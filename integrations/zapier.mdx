The Nyckel Zapier integration lets you connect any image or text classifier to more than 1,000 apps — no code required. You build workflows visually in Zapier's editor, so you can route classification results to other tools the moment a prediction is made.

## What you can do

Common use cases include:

- **Auto-classify incoming emails** — run each new message through a sentiment or topic classifier, then file or forward it based on the result.
- **Moderate user-submitted content** — trigger a safety or content classifier whenever a new image or text is submitted through a form or CMS.
- **Tag support tickets** — classify incoming tickets by category or urgency and route them to the right queue automatically.

Any Nyckel classification function can be used as a Zapier action or trigger, so you can mix and match classifiers with the Zapier app catalog.

## Prerequisites

<Note>
  You need an active Nyckel function before setting up a Zap. If you haven't created one yet, follow the [text classification quickstart](/quickstarts/text-classification) or [image classification quickstart](/quickstarts/image-classification) first.
</Note>

## Get started

Visit the Nyckel page on Zapier to browse available triggers and actions, and connect your Nyckel account:

<Card
  title="Nyckel on Zapier"
  icon="zap"
  href="https://zapier.com/apps/nyckel/integrations"
>
  Browse integrations and connect Nyckel to your workflow.
</Card>

Once you've authorized the Nyckel app in Zapier, select your function from the dropdown in the Zap editor and map your input fields. Zapier will invoke the function and pass the label and confidence score to the next step in your workflow.
