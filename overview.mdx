## What you can build

| Function type | What it does |
| --- | --- |
| **Classification** | Assigns a single label to text, image, or tabular input |
| **Tags** | Assigns multiple labels to a single input |
| **Search** | Returns the most semantically similar items from a corpus |
| **Detection** | Locates and classifies objects within images |
| **OCR** | Extracts text from images |

## How it works

Every Nyckel function follows the same lifecycle:

1. **Create** — define a function with an input type (`Text`, `Image`, or `Tabular`) and an output type (e.g., `Classification`)
2. **Add samples** — upload examples of your input data
3. **Annotate** — label each sample with the correct output
4. **Invoke** — call the `/invoke` endpoint; Nyckel trains automatically in the background and returns predictions immediately

The model retrains every time you add or annotate new samples, so accuracy improves continuously without any action on your part.
